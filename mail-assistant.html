Welcome

This assistant reads your Gmail, learns how you write, and drafts replies that sound like you — all from your browser. Nothing is sent to any server except Google and Anthropic directly. Two one-time setup steps:

1. Google OAuth Client ID

Lets the app sign you into Gmail. Create one (free) in the Google Cloud Console:

  1. Open Google Cloud Console → enable the Gmail API.
  2. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID.
  3. Application type: Web application.
  4. Under Authorized JavaScript origins, add this page's origin:
  5. Copy the Client ID and paste it in Settings.

2. Anthropic API Key

Powers the "sound like me" reply generation with Claude. Get one at console.anthropic.com, then paste it in Settings.
