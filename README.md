# Jake's Steakhouse & Seafood

Ultra-modern single-page website for Jake's Steakhouse & Seafood — historic downtown Tehachapi, California.

- **Address:** 213 S Curry St, Tehachapi, CA 93561
- **Phone:** (661) 822-6015
- **Hours:** Open 7 days a week, 11:30 AM – 9:00 PM

Static site (`index.html`) built with Tailwind CDN, custom CSS animations, and vanilla JS. No build step required — open `index.html` or serve the folder.
